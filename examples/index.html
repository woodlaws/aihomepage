PROCESS

이 사례들은 이렇게 만들어졌습니다

AI홈페이지스쿨의 제작사례는 단순 템플릿 복사가 아닙니다. 각자의 사업과 목적에 맞게 기획하고, AI 도구를 활용해 구조를 잡고, 직접 수정하고 배포하는 방식으로 완성합니다.

1단계
ChatGPT로 기획
·사업 소개 정리
·고객 대상 분석
·사이트맵 작성
·카피 초안 작성
·이미지 방향 설정
2단계
Claude Design / Codex로 제작
·메인페이지 제작
·서브페이지 구성
·반응형 점검
·버튼과 폼 연결
·디자인 수정
3단계
GitHub / Vercel 배포
·저장소 세팅
·Vercel 배포
·URL 확인
·커스텀 도메인 연결
·OG 이미지와 파비콘 적용
4단계
schemaWorks 점검
·메타태그 확인
·헤딩 구조 점검
·구조화 데이터 확인
·sitemap.xml · robots.txt 점검
·AIO 최적화 항목 개선

TYPES

이런 홈페이지를 만들 수 있습니다

AI홈페이지스쿨은 특정 업종만을 위한 과정이 아닙니다. 1인기업, 소상공인, 강사, 컨설턴트, 프리랜서, 마케터가 자신의 상황에 맞는 공식 홈페이지를 직접 만들 수 있도록 설계되어 있습니다.

1
1인기업 홈페이지
서비스 소개, 대표자 브랜딩, 상담 CTA
2
소상공인 매장 홈페이지
매장 소개, 위치, 메뉴·서비스, 문의 연결
3
강사·컨설턴트 홈페이지
프로필, 강의 과정, 후기, 신청 버튼
4
프리랜서 포트폴리오
작업 사례, 서비스 범위, 문의 폼
5
교육 과정 랜딩페이지
커리큘럼, 가격, FAQ, 수강신청 CTA
6
병원·전문 서비스 소개 페이지
전문성, 진료·서비스 안내, 위치, 문의 흐름
7
농산물·상품 상세 랜딩페이지
상품 스토리, 장점, 후기, 구매·문의 연결
8
대행·컨설팅 서비스 페이지
문제 제기, 해결 방식, 프로세스, 상담 신청
CHANGE

수업 전과 후,
가장 큰 차이는 '공식 링크'입니다

수업 전
✕블로그와 SNS에 정보가 흩어져 있습니다.
✕고객에게 보낼 공식 링크가 없습니다.
✕서비스 소개가 매번 말로 설명됩니다.
✕홈페이지 제작과 배포가 막막합니다.
✕검색 등록과 도메인 연결이 어렵게 느껴집니다.
✕AI가 내 사업을 이해할 구조가 부족합니다.
수업 후
✔내 사업 공식 홈페이지가 생깁니다.
✔서비스, 후기, 문의 CTA가 한곳에 정리됩니다.
✔고객에게 보낼 수 있는 공식 URL이 생깁니다.
✔GitHub와 Vercel로 직접 배포할 수 있습니다.
✔도메인, OG 이미지, 검색 등록 흐름을 이해합니다.
✔schemaWorks로 AIO 최적화 상태를 점검할 수 있습니다.
✔이후에도 Claude와 Codex로 직접 수정할 수 있습니다.
ASSETS

4주 후, 이런 제작 자산이 남습니다

1
홈페이지 기획안
사이트맵, 카피, 브랜드 톤앤매너가 정리된 설계 문서
2
ChatGPT 이미지 세트
목업 이미지와 업종별 실사 이미지 세트
3
반응형 멀티페이지 홈페이지
Claude Design 또는 Codex로 제작한 실제 웹사이트
4
GitHub 저장소
수정 이력과 버전 관리가 가능한 코드 저장소
5
Vercel 배포 URL
외부에 공유할 수 있는 실서비스 주소
6
커스텀 도메인
내 사업 이름으로 연결된 공식 홈페이지 주소
7
검색 등록 준비
sitemap.xml, robots.txt, 네이버·구글 등록 흐름
8
AIO 점검 결과
schemaWorks를 활용한 구조, 메타, 헤딩, 구조화 데이터 점검
9
수정 프롬프트 라이브러리
스스로 홈페이지를 수정하고 확장할 수 있는 프롬프트 모음

중요한 것은 완벽한 디자인보다
실제로 운영 가능한 홈페이지입니다

AI홈페이지스쿨은 디자인만 예쁜 화면을 만드는 과정이 아닙니다. 내 사업을 설명하고, 고객에게 공유하고, 검색엔진에 등록하고, AI가 이해할 수 있도록 구조를 점검하는 실전형 홈페이지 제작 과정입니다.

수강생 제작사례는 앞으로 계속 업데이트됩니다. 각자의 업종과 준비 자료에 따라 결과물은 달라질 수 있지만, 중요한 것은 내 사업의 공식 홈페이지를 직접 만들고 운영할 수 있는 경험을 갖는 것입니다.

다음 제작사례는
당신의 홈페이지가 될 수 있습니다

AI홈페이지스쿨에서 내 사업의 공식 홈페이지를 직접 기획하고, 제작하고, 배포하고, AIO 최적화까지 점검해 보세요.
