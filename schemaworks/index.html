PROBLEM

홈페이지를 만들었는데,
AI가 이해하지 못한다면?

홈페이지가 있다고 해서 검색엔진과 AI가 자동으로 잘 이해하는 것은 아닙니다. 제목, 설명, 헤딩 구조, 사이트맵, 구조화 데이터, FAQ, 회사 정보가 제대로 정리되어 있지 않으면 AI는 우리 홈페이지의 의미를 정확히 파악하기 어렵습니다.

1
제목과 설명이 불명확합니다
페이지 title과 description이 정리되어 있지 않으면 검색 결과와 AI 이해에 불리합니다.
2
헤딩 구조가 엉켜 있습니다
H1, H2, H3 구조가 불명확하면 페이지의 주제와 정보 계층을 파악하기 어렵습니다.
3
구조화 데이터가 없습니다
Schema.org 정보가 없으면 회사, 서비스, FAQ, 연락처 정보를 검색엔진이 구조적으로 이해하기 어렵습니다.
4
사이트맵과 robots.txt가 없습니다
검색엔진과 AI 크롤러가 어떤 페이지를 읽어야 하는지 안내하지 못합니다.
5
공식 정보가 흩어져 있습니다
회사명, 대표자명, 주소, 연락처, 서비스명이 페이지마다 다르면 AI가 같은 브랜드로 인식하기 어렵습니다.
6
점검 기준 없이 감으로 수정합니다
무엇을 고쳐야 하는지 알 수 없으면 홈페이지 개선이 막연해집니다.
그래서 AI홈페이지스쿨은 감이 아니라 진단 기준으로 홈페이지를 개선합니다.
WHAT IS SCHEMAWORKS

schemaWorks는 무엇을 진단하나요?

REAL CASE

진단하고, 고치고, 다시 검증하는 홈페이지 제작 과정

AI홈페이지스쿨은 홈페이지 화면을 만드는 데서 끝나지 않습니다. 배포한 뒤 GA4를 설치해 방문자 데이터를 측정하고, schemaWorks로 SEO·GEO·AIO 상태를 진단합니다. sitemap.xml, robots.txt, 구조화 데이터, BreadcrumbList, 메타태그, GA4 설치 여부처럼 부족한 항목을 확인하고, Claude와 Codex로 수정한 뒤 다시 검사합니다.

실습 흐름
1. GA4 설치
방문자 유입과 실시간 데이터 확인
2. schemaWorks 진단
SEO·GEO·AIO 기술 상태 점검
3. 기술 항목 개선
sitemap, robots, 구조화 데이터, BreadcrumbList, lang
4. 재검사와 운영
검색엔진과 AI가 이해하기 쉬운 구조로 개선

처음부터 완벽한 홈페이지를 만드는 것이 목표가 아닙니다. 먼저 진단하고, 문제를 확인하고, Claude와 Codex를 활용해 수정하고, 다시 진단하면서 홈페이지를 AIO 친화적인 구조로 개선하는 것이 핵심입니다.

특정 점수를 보장하지는 않습니다. 다만 수업에서는 schemaWorks 진단 기준을 바탕으로 홈페이지의 SEO·GEO·AIO 최적화 항목을 이해하고, 부족한 부분을 직접 개선하는 방법을 실습합니다.
PROCESS

AI홈페이지스쿨에서는 이렇게 활용합니다

1단계
홈페이지 제작
ChatGPT로 기획하고 Claude Design/Codex로 멀티페이지 홈페이지를 제작합니다.
2단계
schemaWorks 진단
완성된 홈페이지 URL을 schemaWorks에 입력해 AIO 최적화 상태를 진단합니다.
3단계
문제 항목 확인
메타태그, 헤딩, 구조화 데이터, 사이트맵, robots.txt, FAQ, CTA 등 부족한 항목을 확인합니다.
4단계
Claude/Codex로 개선
진단 결과를 바탕으로 수정 프롬프트를 만들고, Claude 또는 Codex로 홈페이지를 개선합니다.
5단계
재진단
수정 후 다시 schemaWorks로 점수를 확인하고 추가 개선 방향을 잡습니다.
이 과정을 통해 수강생은 단순히 홈페이지를 만드는 것에서 끝나지 않고, 자신의 홈페이지를 스스로 진단하고 개선하는 방법까지 익히게 됩니다.
