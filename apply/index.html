FAQ

자주 묻는 질문

코딩을 몰라도 참여할 수 있나요? +
가능합니다. ChatGPT, Claude Design, Codex를 활용해 기획과 제작을 진행하며, GitHub와 Vercel 배포도 초보자 기준으로 안내합니다. 다만 계정 생성, 파일 업로드, 링크 복사, 기본적인 컴퓨터 사용은 직접 할 수 있어야 합니다.
4주 안에 홈페이지를 완성할 수 있나요? +
이 과정은 4주 동안 홈페이지 기획, 이미지 제작, 멀티페이지 구현, 배포, 도메인 연결, 검색엔진 등록까지 단계별로 진행하는 실전 과정입니다. 다만 개인의 준비 자료, 과제 수행 정도, 도메인 연결 환경에 따라 완성도와 세부 설정에는 차이가 있을 수 있습니다.
수업 시간 외에 과제가 있나요? +
네. 자신의 사업 소개 자료, 이미지, 카피, 도메인 정보, 검색 등록 자료 등을 준비해야 합니다. 수업 시간만으로 끝나는 과정이 아니라 실제 홈페이지 완성을 목표로 하는 실습형 과정입니다.
도메인 연결까지 직접 하나요? +
네. Vercel 배포 후 커스텀 도메인 연결 방법을 실습합니다. 도메인 구매처와 DNS 설정은 개인별 상황에 따라 다를 수 있습니다.
네이버와 구글 검색 등록도 배우나요? +
네. 네이버 서치어드바이저와 구글 서치콘솔 등록, sitemap.xml 제출, 색인 요청까지 다룹니다.
schemaWorks 점수를 보장하나요? +
특정 점수를 보장하지는 않습니다. 사이트 상태, 준비 자료, 도메인, 기술 환경에 따라 결과는 달라질 수 있습니다. 다만 수업에서는 schemaWorks 진단 기준을 바탕으로 SEO·GEO·AIO 최적화 항목을 이해하고, 부족한 부분을 직접 개선하는 방법을 실습합니다.
GA4도 수업에서 다루나요? +
네. 홈페이지를 배포한 뒤 GA4를 설치해 방문자 데이터와 실시간 유입을 확인하는 흐름을 다룹니다. 단순히 홈페이지를 만드는 데서 끝나지 않고, 실제 운영과 측정이 가능한 상태까지 연결하는 것이 목표입니다.
홈페이지를 만든 뒤에도 수정할 수 있나요? +
네. GitHub, Vercel, Claude, Codex를 활용해 수업 이후에도 스스로 문구, 이미지, 페이지, 기술 항목을 수정할 수 있도록 유지보수 흐름을 함께 다룹니다.
도메인 비용이나 유료 도구 비용이 포함되어 있나요? +
아닙니다. 수강료에는 교육과 실습 안내가 포함되며, 도메인 구매비, 유료 AI 도구 이용료, 외부 서비스 비용은 개인별 상황에 따라 별도 발생할 수 있습니다.
홈페이지 제작을 대신해주는 과정인가요? +
아닙니다. AI홈페이지스쿨은 대신 제작해주는 대행 서비스가 아니라, 본인이 직접 자신의 홈페이지를 기획하고 제작하고 배포하는 실습 과정입니다. 다만 수업 중 프롬프트와 실습 흐름을 안내하며, 막히는 부분을 함께 해결합니다.
이미 홈페이지가 있어도 들을 수 있나요? +
가능합니다. 기존 홈페이지를 리뉴얼하거나, 새 랜딩페이지와 서브페이지를 추가하거나, schemaWorks를 통해 AIO 최적화 상태를 점검하는 목적으로도 활용할 수 있습니다.
